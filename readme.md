This project focuses on creating a custom image dataset and training a YOLO-based object detection model to classify two animal species: lions and tigers. The goal was to build a complete workflow starting from gathering images, organizing them into class folders, and generating annotations. LabelMe was used for labeling, and custom scripts were developed to rename files, convert annotations into YOLO format, and prepare the dataset structure. After preprocessing, the YOLO model was trained on this dataset and fine-tuned to improve accuracy on the two classes. The project also includes scripts for evaluation and inference, allowing the trained model to be tested on new images. Overall, the work demonstrates how to build a practical end-to-end detection pipeline, from dataset creation to model deployment, using a simple and manageable dataset.
